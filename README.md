# Portal Tools RF

Halaman menu berisi kumpulan tool HTML tim RF, dibuka lewat satu link GitHub Pages.

- `index.html`  halaman menu
- `menu.js`     daftar menu (edit file ini untuk tambah/hapus tool)
- `apps/`       file HTML tiap tool
- `assets/`     logo

Menambah tool: simpan HTML ke `apps/`, lalu tambahkan satu blok di `TOOLS` pada `menu.js`.
